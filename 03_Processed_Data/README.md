# Processed Data

All datasets in this folder have been standardized to:

- Resolution: 30 m
- CRS: WGS 84 / UTM Zone 45N (EPSG:32645)

## Subfolders

- **Factors_30m/** : All 11 conditioning factor rasters
- **FR_Tables/** : Frequency Ratio values for each class of every factor
- **Inventory/** : Training (70%) and Testing (30%) landslide points
