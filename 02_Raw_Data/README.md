# Raw Data

This folder contains the original input datasets used in the study.

## Contents

- **DEM/** : Digital Elevation Model (SRTM, 30 m)
- **Inventory/** : Landslide inventory (shapefile + KMZ)
- **Study Area/** : Boundary of Udayapur District
- **Vector/** : Geology, Soil, River, and Road layers

All data are in WGS 84 / UTM Zone 45N (EPSG:32645) or were reprojected to this system during processing.

See `01_Documentation/Data_Sources_and_Dictionary.md` for detailed source information.
