# Landslide Susceptibility Mapping – Udayapur District

**Open Research Project | Frequency Ratio Method | Peer-reviewed Publication**

**Pramod Subedi**

---

### Overview
Reproducible GIS-based landslide susceptibility mapping of Udayapur District, Eastern Nepal, using the Frequency Ratio method. Originally developed in ArcGIS and fully replicated with open-source Python tools.

### Key Achievements
- First district-wide landslide susceptibility map for Udayapur
- 211 field-verified landslides
- Published in *Applied and Environmental Soil Science* (2026)
- Fully open data + code + documentation
- Corrected open-source replication achieves AUC = 0.822

### Technical Stack
Python (rasterio, geopandas, scikit-learn, jenkspy), ArcGIS (original analysis), Frequency Ratio modelling, ROC/AUC validation
